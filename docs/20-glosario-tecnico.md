# 20. Glosario Técnico

## Introducción
Este glosario define los términos técnicos y científicos más importantes utilizados a lo largo de esta documentación para facilitar su comprensión por parte de desarrolladores junior y senior.

## Términos Científicos (Física de Ondas)

- **Amplitud ($A$):** El valor máximo de desplazamiento de una partícula respecto a su posición de equilibrio. En el sonido, se asocia con el volumen o intensidad.
- **Compresión:** Región de una onda longitudinal donde las partículas del medio están más próximas entre sí, generando una zona de alta presión.
- **Frecuencia ($f$):** El número de ciclos o vibraciones completas por unidad de tiempo. Se mide en Hertz (Hz). En sonido, determina el tono (grave o agudo).
- **Longitud de Onda ($\lambda$):** La distancia física entre dos puntos idénticos de ciclos consecutivos de una onda (por ejemplo, la distancia entre dos zonas de máxima compresión).
- **Onda Longitudinal:** Aquella en la que el movimiento de oscilación de las partículas del medio es paralelo a la dirección de propagación de la onda (como el sonido).
- **Rarefacción:** Región de una onda longitudinal donde las partículas están más separadas entre sí, generando una zona de baja presión.

## Términos de Desarrollo Frontend

- **Canvas 2D:** API de HTML5 que permite el renderizado de gráficos 2D mediante scripts (JavaScript). Es ideal para gráficos de alto rendimiento y videojuegos en web.
- **Delta Time:** El tiempo exacto que transcurre entre el fotograma (*frame*) actual y el anterior. Se usa para que las velocidades de animación sean consistentes sin importar la potencia del procesador.
- **FPS (Frames Per Second):** Cuadros por segundo. Una tasa de 60 FPS significa que la pantalla se actualiza 60 veces en un segundo, dando la sensación de movimiento totalmente fluido.
- **Garbage Collection (GC):** Recolección de Basura. Proceso automático de lenguajes como JavaScript para liberar memoria borrando objetos que ya no se usan.
- **Web Audio API:** Potente sistema del navegador para el control, síntesis y manipulación de audio digital.

## Conclusión
Este glosario cierra la documentación técnica obligatoria para la construcción del simulador de ondas sonoras. Con estos conceptos y las fases descritas, el proyecto está listo para ser desarrollado.
